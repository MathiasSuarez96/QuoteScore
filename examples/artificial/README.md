# Ejemplos completamente artificiales

Estas cuatro oportunidades se inventaron desde cero para probar QuoteScore. No son registros anonimizados ni variaciones de casos comerciales reales.

La entrada contiene tres propuestas iniciales, tres opciones, un componente de hotel y una transacción ficticia. La segunda opción tiene pasajeros contradictorios y alcance de precio desconocido a propósito. Dos oportunidades se parecen documentalmente y generan sospechas sin probar identidad.

`python -m tools.run_demo` carga el lote, confirma explícitamente un desenlace parcial y una pérdida, rechaza una hipótesis de agrupación y genera un reporte. `python -m tools.build_demo` regenera los CSV públicos desde reglas de construcción independientes.

No reemplazar estos archivos por datos reales. Para uso privado, elegir rutas externas al proyecto y respetar el alcance permitido registrado.
