# QuoteScore — resumen ejecutivo

QuoteScore es una iniciativa personal de práctica y portfolio que busca ayudar a organizar oportunidades de viaje y priorizar el seguimiento comercial con información confiable. La primera entrega construye una base auditable para aprender qué se cotizó, qué se vendió y qué sigue sin confirmarse.

La base local permite cargar tablas, detectar errores, revisar agrupaciones y conservar el historial de decisiones. Una demostración artificial recorre el flujo completo. Las ventas parciales cuentan como conversión del viaje; los cambios de destino mantienen la oportunidad cuando continúa la misma necesidad. Los casos abiertos no se consideran perdidos por silencio.

La información inicial se reconstruye al momento de enviar la primera propuesta con precio. Los datos del cierre se guardan aparte para evitar que una evaluación futura use información que el asesor todavía no tenía. Los datos ambiguos conservan su incertidumbre y no se rellenan para mejorar artificialmente la calidad.

Todavía no existe un score validado, un dashboard comercial ni una interfaz visual. Tampoco se cargaron fuentes comerciales reales en esta entrega. Para avanzar se necesitan fuentes cuyo uso esté permitido, transcripciones sanitizadas de propuestas y desenlaces, y evidencia para conciliar los casos. El alcance de uso fuera de la empresa sigue pendiente de registro.

La siguiente entrega reconstruirá datos y medirá cobertura, faltantes y decisiones pendientes. Después se hará un análisis descriptivo para decidir si existe evidencia suficiente para probar un modelo sencillo. Su utilidad se evaluará según calidad de datos, representatividad y resultados de validación; no se promete precisión ni aumento de ventas. Una asociación con la compra no demuestra que un seguimiento cause esa venta.

Como evolución se prevén Power BI para comunicar el panorama y una app local con formulario y listado de oportunidades. Puede existir una herramienta útil de registro y seguimiento antes de contar con probabilidades justificadas. Este resumen queda como documentación local; no se envió ni publicó.
